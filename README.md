# Firefly Garden
Install Python 3.10+ and open a terminal in this folder.

    python -m pip install -r requirements.txt
    python -m streamlit run app.py

Open the local URL printed in the terminal. For Streamlit Community Cloud, upload app.py and requirements.txt to a GitHub repository and select app.py as the entrypoint.

The two scenarios use synthetic objective functions for teaching, not real-world data. The implementation is a simplified synchronous Firefly Algorithm variant.
